# A bet is a commitment: protected time, no default extension

**Rule:** Once a team is committed to a time box, shield it from interruptions and stop the project at the deadline rather than extend it; re-shape and re-pitch instead.

**Why:** Momentum needs an unbroken curve of time, so a "quick one-day" pull costs more than a day. The most you can lose is the time box. A default stop prevents runaway projects, never lets one project block better work, and signals a shaping failure rather than a people failure. A small overrun is allowed only when every remaining task is a true must-have and nothing is still unsolved; unknowns at the end mean a hole in the concept.

**Do:**
```
during the cycle: new request -> next-cycle consideration, not the team
only data loss, outage or wide breakage interrupts
at deadline: shipped? ok. else stop and reshape
extend (<= ~2 weeks) only if all remaining work is must-have and nothing is open
```

**Don't:** Lend the team "for a few hours", or grant days because it is nearly done while questions remain.

**Break it when:** A genuine crisis, which is rare.
