# Push up a big tent

**Rule:** Welcome anyone, and make the bar explicit and identical for everyone: a reproducible report, a test that fails without the fix, docs and changelog updated.

**Why:** Maintainer time is the scarce resource. A visible bar lets strangers succeed without private negotiation, and diverse contributors find problems the core team misses.

**Do:**
```
bug report   = failing test built from a template
feature idea = discuss first; code (or a partner who writes it) moves it
every merged contribution is credited publicly
patch with only cosmetic change: declined with a stated reason
```

**Don't:** Leave contributors guessing what is required, or reject a patch for taste with no stated criterion.

**Break it when:** A patch is outside the project's promise. Say so, with the reason.

**Source:** Doctrine: https://rubyonrails.org/doctrine (Push up a big tent). Guide: https://guides.rubyonrails.org/contributing_to_ruby_on_rails.html (Create an Executable Test Case, What about Feature Requests?, Write Your Code, Rails Contributors, Testing Patches). Docs only: no code enforces it.
