# Push up a big tent

**Rule:** Welcome people with different tastes. Do not require agreement on every point to belong.

**Why:** A narrow community stagnates. Diverse contributors find the problems and ideas the core team misses.

**Do:**
```
accept a patch that serves a use the maintainers don't have
share the roadmap, credit contributors, document how to join
```

**Don't:** Reject a contribution only because it is not how you would do it.

**Break it when:** A change harms the framework's core promise. Say so clearly and kindly.

**Source:** Rails Doctrine, "Push up a big tent".
