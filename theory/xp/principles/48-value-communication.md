# Value: communication

**Rule:** Treat everyone as part of the team, talk face to face daily, and work together on everything from requirements to code.

**Why:** The aim is the best solution the team can find together. Face-to-face talk is faster and more reliable than anything else. XP programmers constantly talk with customers and fellow programmers.

**Do:**
```
talk in person first; walk over rather than write
include customers from requirements onward
```

**Don't:** Substituting documents and tools for conversation.

**Break it when:** The site names no exception.

**Source:** http://www.extremeprogramming.org/values.html, http://www.extremeprogramming.org/lessons.html, http://www.extremeprogramming.org/index.txt
