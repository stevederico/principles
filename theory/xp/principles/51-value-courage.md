# Value: courage

**Rule:** Tell the truth about progress and estimates, adapt when changes arrive, and plan to succeed instead of documenting excuses for failure.

**Why:** Fear fades because no one works alone. With the other values in place, programmers can respond to changing requirements and technology courageously.

**Do:**
```
report real progress and honest estimates
change course when requirements change
do not write excuse documents
```

**Don't:** Documenting excuses for failure in advance.

**Break it when:** The site names no exception.

**Source:** http://www.extremeprogramming.org/values.html, http://www.extremeprogramming.org/index.txt
