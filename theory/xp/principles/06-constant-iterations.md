# Constant short iterations

**Rule:** Split the schedule into about a dozen iterations of one to three weeks, prefer one week, and keep the length the same all project.

**Why:** The fixed length is the project's heartbeat; the constant is what makes measuring progress and planning simple and reliable. One week is called the best choice even though it feels short. A team finishing many stories per iteration should try a shorter one.

**Do:**
```
iteration_length = 1 week        # same for the whole project
repeat: plan -> build -> demo -> next
if team finishes many stories each time: shorten, do not stretch
```

**Don't:** Varying iteration length to fit the work.

**Break it when:** The site names no exception.

**Source:** http://www.extremeprogramming.org/rules/iterative.html, http://www.extremeprogramming.org/lessons.html
