# Coding standards

**Rule:** Write all code to a standard the team has agreed.

**Why:** Consistent code is easy for everyone to read and refactor, and code that looks the same encourages collective ownership.

**Do:**
```
agree a format as a team; apply it to every file
anyone editing any file follows it
```

**Don't:** Each person keeping a private style.

**Break it when:** The site names no exception.

**Source:** http://www.extremeprogramming.org/rules/standards.html
